# IBL Command Center V2 Phase 1

This directory contains the local development deployment skeleton only.

MIAB IMAP and Resend are intentionally absent. Provider capabilities are seeded as UNVERIFIED and no Phase 1 API can promote them. The Compose network is private and no public deployment configuration is included.

The web application uses Node 24.18.0 for Next 16/Turbopack. Bun 1.3.12 remains the locked package manager and runs the API and Eve agent.
